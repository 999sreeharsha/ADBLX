# ADBLX Filter Distribution Backend

This directory distributes trusted filter list updates to ADBLX clients. It
is not an API server — it is static data, published as-is.

See `docs/superpowers/specs/2026-07-26-sprint6-commit1-backend-repo-architecture-design.md`
in the repository root for the full architecture and directory ownership
model.

Content beyond this overview (publishing guide, manifest schema, update
workflow) is deferred to later Sprint 6 commits.
