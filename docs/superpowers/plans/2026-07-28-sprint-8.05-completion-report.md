# Sprint 8.05 — Foundation Closure — Completion Report

**Date:** 2026-07-28

## Summary

Sprint 8.05 closed the remaining infrastructure, operational, and manual
verification items carried over from Sprint 8.0, per
`docs/superpowers/specs/2026-07-28-sprint-8.05-foundation-closure-design.md`.

## Delivered

1. **Manifest hosting** — production manifest and filter payloads are served
   via GitHub Pages from a `gh-pages` branch of this repo
   (`https://harshaunofficial.github.io/ADBLX/manifest.json`).
   `AppManifestEndpointProvider` (`ADBLX/AppCompositionRoot.swift`) now
   points at this URL. `backend/tools/publish-pages.sh` deploys
   `backend/public/` to `gh-pages` via a self-bootstrapping, idempotent
   `git worktree` script, documented in `docs/Architecture/Publisher.md`.
   The first live push and enabling GitHub Pages in repo settings remain an
   operational step for the repository owner.
2. **App Store setup** — `docs/AppStoreSetup.md` documents the canonical
   StoreKit product IDs (from `Config/Configuration.storekit`), the App
   Store Connect configuration steps, and a Sandbox verification checklist
   tied to Sprint 8.0's `EntitlementService`, with an operational status log.
   **StoreKit was treated as canonical** ($19.99 annual / $49.99 lifetime).
   PRD v1.1 still lists older $14.99 / $39.99 pricing — that discrepancy
   remains an **open product decision** and was **not** resolved by
   Sprint 8.05 (the PRD was not rewritten).
3. **Manual verification** — `docs/Architecture/ManualVerification.md` now
   covers all four Content Blocker extensions (Ads, Privacy, Annoyances,
   Regional) against `Compiled/<Group>.json` and current `AppGroup` log
   strings, each split into Automatable and Manual steps. The Ads section
   was modernized from the obsolete Sprint 0 `Rules/Ads.json` checklist
   before the other three sections were derived from it.
4. **Product decision — premium revocation policy** — `docs/gotchas.md`'s
   entitlement-gating entry status changed from **deferred** (Sprint 8.0) to
   **required before the Sprint 8.1 Release Candidate** (Sprint 8.05,
   2026-07-28), because the upcoming DNS Packet Tunnel introduces a second
   enforcement surface that makes an un-revoked premium filter a live
   problem.

## Open product decisions carried forward

- **PRD vs StoreKit pricing** — `.storekit` ($19.99 / $49.99) vs PRD v1.1
  ($14.99 / $39.99). Foundation Closure followed `.storekit` for App Store
  documentation; product must reconcile PRD pricing separately.

## Foundation Phase: Complete

Per the design spec's Sprint Exit Criteria, all items are satisfied:

- Manifest hosting path implemented and documented.
- Deployment script exists, self-bootstrapping and idempotent.
- Manifest endpoint points to the production Pages URL.
- App Store setup documentation exists.
- Apple operational setup is documented and accompanied by repeatable
  verification checklists.
- Manual verification exists for all four Content Blockers.
- Premium revocation policy is promoted to a Sprint 8.1 blocker.
- This completion report is published.

**Completion of Sprint 8.05 marks the formal end of the Foundation Phase.
All subsequent implementation work belongs to the Release 1.0 phase of the
project.**
