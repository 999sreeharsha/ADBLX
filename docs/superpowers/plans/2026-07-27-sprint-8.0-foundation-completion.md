# Sprint 8.0 — Foundation Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every known correctness gap in the update pipeline, bring all four Content Blockers onto the same App-Group/bundled-fallback runtime architecture, and lay StoreKit foundation with entitlement-gated planning — completing production readiness ahead of Sprint 8.1 (DNS) and Sprint 8.5 (Safari MVP).

**Architecture:** One transactional update pipeline (`UpdateCoordinator` → `FilterPipeline` → `FilterStore`) grows a `.remove` path that reuses the same composition/compile/write/rollback machinery as `.install`, backed by a new canonical local cache (`Filters/`) so recomposition never needs the network. The four Content Blocker extensions converge on one already-proven runtime pattern (App Group read, bundled fallback, structured logging) via pure duplication, not abstraction. StoreKit lands behind a narrow `EntitlementService` protocol consumed by the same planner that already guards premium filters.

**Tech Stack:** Swift 6.3, Swift Testing (`@Suite`/`@Test`/`#expect`), SwiftUI/`@Observable`, StoreKit 2, XcodeGen (`project.yml`), GitHub Actions CI.

**Spec:** `docs/superpowers/specs/2026-07-27-sprint-8.0-foundation-completion-design.md` — read it in full before starting; every task below implements a specific section of it.

## Global Constraints

- Every actor-boundary-crossing helper touched by these tasks that is called from launch-time code must stay `nonisolated` or run inside a detached, off-main-actor `Task` — this project's `SWIFT_DEFAULT_ACTOR_ISOLATION` is `MainActor` (see `project.yml`), so unannotated new declarations default to main-actor isolation unless explicitly marked otherwise.
- All filesystem mutations to the App Group container go through `FilterStore` — no other type touches `FileManager` against the App Group directly (existing invariant, restated in the spec's Architectural Constraints).
- `installGroup()` (the shared internal composition/compile/write/reload path used by both `install` and `remove`) must stay pure: `[FilterSource] → compiled → written → reloaded`. It must never know whether its sources came from network, disk, or bundled snapshot.
- `.install` and `.remove` share one pipeline. Do not introduce a second, parallel removal code path.
- No new persistent state goes into `UserDefaults` — new update-subsystem state (throttle, etc.) goes into `FilterStore`'s `Metadata/` directory, consistent with `installed_filters.json`/`statistics.json`/`manifest.json`.
- Tests in this codebase run against the real `FilterStore(appGroupIdentifier: AppGroup.identifier)` (real App Group container on the test-runner machine/simulator), not a mock filesystem — see `ADBLXTests/Filtering/FilterStoreTests.swift` and `FilterPipelineTests.swift` for the established pattern. New tests must follow this pattern and clean up any files they create that aren't naturally overwritten by the next test run.
- All Swift Testing suites in `ADBLXTests/Filtering/` that touch the shared App Group container are marked `@Suite("...", .serialized)` — new suites touching shared App Group state must do the same to avoid cross-test interference.
- Every task must build cleanly and pass the full existing test suite before being considered done — no task may intentionally leave the build red for a later task to fix (see `docs/gotchas.md`'s note on broken-build task splits).

```swift
enum ContentBlockerBootstrap {
    private static let logger = Logger(
        subsystem: Bundle.main.bundleIdentifier ?? "com.ADBLX.ADBLX",
        category: "Bootstrap"
    )

    /// `nonisolated`: called from a detached, off-main-actor Task at launch — see the plan's
    /// Global Constraints note on SWIFT_DEFAULT_ACTOR_ISOLATION.
    ///
    /// Gated solely by `ManifestStore.load() == nil` (Sprint 8.0 Commit 1) — once the first
    /// production update commits a cached manifest, this never writes again. No additional
    /// bootstrap flag is introduced.
    @discardableResult
    nonisolated static func ensureInitialRulesInstalled(
        pipeline: FilterPipeline,
        manifestStore: ManifestStore
    ) async -> Bool {
        do {
            if try await manifestStore.load() != nil {
                logger.info("Cached manifest present — skipping bundled snapshot bootstrap")
                return false
            }
        } catch {
            logger.error("ManifestStore.load() failed during bootstrap gate check: \(error, privacy: .public)")
            return false
        }

        do {
            let result = try await pipeline.installBundledSnapshotIfNeeded()
            logger.info("Filter pipeline installed \(result.installedRuleCount) rule(s) for \(result.group.rawValue, privacy: .public)")
            return true
        } catch {
            logger.error("Filter pipeline install failed: \(error, privacy: .public)")
            return false
        }
    }
}
```

Note: `manifestStore.load()` per `ManifestStore.swift` already returns `nil`
(not a thrown error) when nothing is cached yet — the `catch` block above
only fires on a genuine read/decode failure, which this task treats as
"don't bootstrap" (fail safe, don't overwrite) rather than "bootstrap
anyway."

```swift
// ADBLX/Filtering/Updates/UpdateThrottle.swift
import Foundation

/// Persists the timestamp of the last *successful* update and answers whether enough
/// time has elapsed to attempt another one. Scheduling policy — not a transactional
/// concern of UpdateCoordinator itself, per Sprint 8.0's "throttle policy stays outside
/// the transactional actor" design decision. Stored as its own metadata file
/// (`update_throttle.json`), not folded into CachedManifest (a transport-cache
/// concept) or UserDefaults (not naturally grouped with the rest of update state).
struct UpdateThrottleRecord: Codable, Equatable {
    var lastSuccessAt: Date
}

actor UpdateThrottle {
    private static let filename = "update_throttle.json"

    private let store: FilterStore
    private let interval: TimeInterval

    init(store: FilterStore, interval: TimeInterval) {
        self.store = store
        self.interval = interval
    }

    /// `true` when no successful update has ever been recorded, or the interval since
    /// the last one has fully elapsed.
    func shouldRun(now: Date) async -> Bool {
        guard let record = await loadRecord() else { return true }
        return now.timeIntervalSince(record.lastSuccessAt) >= interval
    }

    /// Called only on `UpdateCoordinator.run()`'s success paths (`.upToDate`, `.updated`) —
    /// never on `.rolledBack`/`.rollbackFailed`/a thrown error, so a failed update remains
    /// retryable on the next launch.
    func recordSuccess(at date: Date) async throws {
        let record = UpdateThrottleRecord(lastSuccessAt: date)
        let data = try JSONEncoder().encode(record)
        try await store.writeMetadata(data, filename: Self.filename)
    }

    private func loadRecord() async -> UpdateThrottleRecord? {
        guard let data = try? await store.read(Self.filename, in: .metadata) else { return nil }
        return try? JSONDecoder().decode(UpdateThrottleRecord.self, from: data)
    }
}
```

```swift
actor UpdateCoordinator {
    private let manifestClient: ManifestClient
    private let manifestStore: ManifestStore
    private let downloadClient: FilterDownloadClient
    private let pipeline: FilterPipeline
    private let store: FilterStore
    private let reloader: ReloadCoordinator
    private let extensionIdentifiers: GroupExtensionIdentifiers

    // init unchanged

    /// Public entry point. Concurrent callers while a transaction is already running
    /// await the same in-flight Task rather than starting a second transaction — actor
    /// isolation alone only serializes execution, it does not prevent two full
    /// transactions from each running to completion (Sprint 8.0 Commit 2).
    func run(onPhaseChange: @escaping (UpdatePhase) -> Void = { _ in }) async throws -> UpdateRunResult {
        if let inFlightTask {
            return try await inFlightTask.value
        }
        let task = Task { try await runTransaction(onPhaseChange: onPhaseChange) }
        inFlightTask = task
        defer { inFlightTask = nil }
        return try await task.value
    }

        // ... existing body of run(), unchanged, moved here verbatim ...
```

- [ ] **Step 3: Extract `installGroup()` and implement `remove()` in `FilterPipeline`**

In `ADBLX/Filtering/Pipeline/FilterPipeline.swift`, restructure `install` to
delegate to a new private `installGroup`, and add `remove`:

```swift
    /// Installs an entire group's composition in one pass: validate every source, persist
    /// each source's verified raw payload to `Filters/` (Sprint 8.0 Commit 3 — the canonical
    /// local cache `.remove` reads from to recompose without the network), compose them into
    /// one rule set, compile once, partition once, write `Compiled/<Group>.json` once, merge
    /// every source into `installed_filters.json`, then reload per `reloadStrategy`.
    func install(
        _ composition: GroupComposition,
        reloadStrategy: ReloadStrategy = .immediate
    ) async throws -> PipelineResult {
        for source in composition.sources {
            try validator.validate(source.data)
        }
        for source in composition.sources {
            try await store.writeFilterPayload(source.data, filterID: source.filterID)
        }

        let installedFilters: [InstalledFilter] = composition.sources.map { source in
            InstalledFilter(
                id: source.filterID,
                group: composition.group,
                installedVersion: source.version,
                checksumSHA256: source.checksumSHA256,
                // lastUpdated/ruleCount are placeholders overwritten by installGroup once
                // compile statistics are known — see installGroup's merge step below.
                lastUpdated: Date(),
                ruleCount: 0
            )
        }
        return try await installGroup(
            composition,
            upsertingFilterEntries: installedFilters,
            removingFilterIDs: [],
            reloadStrategy: reloadStrategy
        )
    }

    /// Removes one filter from `group`: loads the group's remaining installed sources'
    /// raw payloads from `Filters/`, recomposes the group without `filterID`, and deletes
    /// `filterID`'s entry from `installed_filters.json` and its `Filters/<filterID>.json`
    /// payload. Reuses the same `installGroup` pipeline as `install` — no parallel removal
    /// path (Sprint 8.0 Architectural Constraints).
    func remove(
        filterID: String,
        group: FilterGroup,
        reloadStrategy: ReloadStrategy = .immediate
    ) async throws -> PipelineResult {
        let existingFilters = (try? await loadInstalledFilters()) ?? []
        let remaining = existingFilters.filter { $0.group == group && $0.id != filterID }

        var sources: [FilterSource] = []
        for filter in remaining {
            let data = try await store.readFilterPayload(filterID: filter.id)
            sources.append(FilterSource(
                filterID: filter.id,
                version: filter.installedVersion,
                checksumSHA256: filter.checksumSHA256,
                data: data
            ))
        }

        let composition = GroupComposition(group: group, sources: sources)
        let result = try await installGroup(
            composition,
            upsertingFilterEntries: [],
            removingFilterIDs: [filterID],
            reloadStrategy: reloadStrategy
        )
        try? await store.removeFilterPayload(filterID: filterID)
        return result
    }

    /// Pure composition pipeline shared by `install` and `remove`: compose → compile →
    /// partition → atomic write `Compiled/<Group>.json` → merge `installed_filters.json`
    /// (remove `removingFilterIDs`, then upsert `upsertingFilterEntries`) → write
    /// `statistics.json` → reload per `reloadStrategy`. Knows nothing about where
    /// `composition.sources` originated (network, disk, bundled snapshot) — that's each
    /// caller's responsibility.
    private func installGroup(
        _ composition: GroupComposition,
        upsertingFilterEntries: [InstalledFilter],
        removingFilterIDs: Set<String>,
        reloadStrategy: ReloadStrategy
    ) async throws -> PipelineResult {
        let composed = try compositionService.compose(composition.sources, group: composition.group)
        let compiled = try await compiler.compile(source: composed.data, group: composition.group)
        let partition = try await partitioner.partition(compiled, group: composition.group)

        let destinationURL = try await store.directoryURL(.compiled)
            .appendingPathComponent("\(partition.group.rawValue.capitalized).json")
        try writer.write(partition.json, to: destinationURL)

        var existingFilters = (try? await loadInstalledFilters()) ?? []
        existingFilters.removeAll { removingFilterIDs.contains($0.id) }
        for entry in upsertingFilterEntries {
            let resolved = InstalledFilter(
                id: entry.id,
                group: entry.group,
                installedVersion: entry.installedVersion,
                checksumSHA256: entry.checksumSHA256,
                lastUpdated: compiled.statistics.lastUpdated,
                ruleCount: compiled.ruleCount
            )
            existingFilters.removeAll { $0.id == resolved.id }
            existingFilters.append(resolved)
        }
        let installedFiltersData = try JSONEncoder().encode(existingFilters)
        try await store.writeMetadata(installedFiltersData, filename: "installed_filters.json")

        let statisticsData = try JSONEncoder().encode(compiled.statistics)
        try await store.writeMetadata(statisticsData, filename: "statistics.json")

        let reloadResults: [ReloadCoordinator.ReloadResult]
        if reloadStrategy == .immediate {
            reloadResults = await reloader.reload(extensionIdentifiers: [partition.extensionIdentifier])
        } else {
            reloadResults = []
        }

        return PipelineResult(
            group: composition.group,
            compiledRuleCount: compiled.ruleCount,
            installedRuleCount: partition.ruleCount,
            compileStatistics: compiled.statistics,
            reloadResults: reloadResults
        )
    }
```

Note the `install()` rewrite changes the shape of the metadata-merge from
the original inline version: originally `install` built each
`InstalledFilter` directly with `compiled.statistics.lastUpdated`/
`compiled.ruleCount` inline, because those values weren't known until after
`compiler.compile` ran. In the refactor above, `install()` builds
placeholder `InstalledFilter` entries (with `lastUpdated: Date()`,
`ruleCount: 0`) and passes them to `installGroup`, which **overwrites**
`lastUpdated`/`ruleCount` with the real compiled values before merging —
see the `resolved` reconstruction inside `installGroup`. This preserves the
original behavior exactly (the placeholder values are never actually
written) while letting `installGroup` be the single place that knows the
real compiled statistics.

```swift
        for (group, entries) in installGroups {
            var downloaded: [DownloadedFilter] = []
            for entry in entries {
                downloaded.append(try await downloadClient.download(entry))
            }
            for filter in downloaded {
                try Checksum.verify(fileURL: filter.tempFileURL, against: filter.expectedChecksum)
            }
            downloadedByGroup[group] = downloaded
        }

        // Snapshot before any write in the batch begins — this must capture pre-transaction
        // Filters/ state before any removal in the batch executes (Sprint 8.0 Commit 3).
        let snapshot = try await store.snapshotForRollback()
        let affectedExtensionIDs = Set(
            installGroups.map { extensionIdentifiers[$0.group] } + removals.map { extensionIdentifiers[$0.group] }
        )
        var installedFilterIDs: [String] = []

        onPhaseChange(.installing)
        do {
            // One group composed and installed at a time — keeps at most one group's
            // decoded sources resident in memory (Sprint 3A design doc's <200MB target).
            for (group, _) in installGroups {
                let downloaded = downloadedByGroup[group] ?? []
                var sources: [FilterSource] = []
                for filter in downloaded {
                    // Bridge because FilterPipeline.install is Data-based. If a future
                    // overload accepts a URL directly, this read disappears.
                    let data = try Data(contentsOf: filter.tempFileURL)
                    sources.append(FilterSource(
                        filterID: filter.filterID,
                        version: filter.version,
                        checksumSHA256: filter.expectedChecksum,
                        data: data
                    ))
                }
                let composition = GroupComposition(group: group, sources: sources)
                _ = try await pipeline.install(composition, reloadStrategy: .deferred)
                installedFilterIDs.append(contentsOf: downloaded.map(\.filterID))
            }
            for removal in removals {
                _ = try await pipeline.remove(filterID: removal.filterID, group: removal.group, reloadStrategy: .deferred)
            }
            try await manifestStore.save(manifest, etag: etag)
            let reloadResults = await reloader.reload(extensionIdentifiers: Array(affectedExtensionIDs))
            onPhaseChange(.complete)
            return .updated(installedFilterIDs: installedFilterIDs, reloadResults: reloadResults)
        } catch {
            do {
                try await store.restore(snapshot)
            } catch let restoreError {
                return .rollbackFailed(originalReason: error, restoreError: restoreError)
            }
            _ = await reloader.reload(extensionIdentifiers: Array(affectedExtensionIDs))
            return .rolledBack(reason: error)
        }
```

Note `affectedExtensionIDs` changes from `[String]` (array, allowing
duplicates) to `Set<String>` then back to `Array` at the reload call sites —
this avoids reloading the same extension twice when a single transaction
both installs and removes filters in the same group. This is a minor
behavioral improvement over the pre-existing array (which could already
have duplicates from multiple installs into a group, though today's
`UpdatePlanner` never produces two `.install` actions for the same group in
one plan, so this was latent, not exercised).

```swift
actor FilterDownloadClient {
    private let session: HTTPSession

    /// Dedicated subdirectory under the system temp directory — no other component
    /// writes here. Transactional scratch space only; never a source of truth (Sprint
    /// 8.0 Commit 4's storage-class boundary — see the design spec's glossary).
    nonisolated static let workspaceDirectory = FileManager.default.temporaryDirectory
        .appendingPathComponent("com.ADBLX.ADBLX.Downloads", isDirectory: true)

    init(session: HTTPSession) {
        self.session = session
    }

    func download(_ entry: FilterManifest.Entry) async throws -> DownloadedFilter {
        let (data, response) = try await session.data(for: URLRequest(url: entry.sourceURL))
        guard let httpResponse = response as? HTTPURLResponse else {
            throw FilterDownloadClientError.invalidResponse
        }
        guard httpResponse.statusCode == 200 else {
            throw FilterDownloadClientError.unexpectedStatusCode(httpResponse.statusCode)
        }

        try FileManager.default.createDirectory(
            at: Self.workspaceDirectory, withIntermediateDirectories: true
        )
        let tempURL = Self.workspaceDirectory
            .appendingPathComponent("\(entry.id)-\(UUID().uuidString).tmp")
        try data.write(to: tempURL, options: .atomic)

        return DownloadedFilter(
            filterID: entry.id,
            tempFileURL: tempURL,
            expectedChecksum: entry.checksumSHA256,
            version: entry.version
        )
    }

    /// Empties the entire workspace directory, regardless of its contents — self-healing
    /// against a prior crash that skipped cleanup, per Sprint 8.0 Commit 4. Called once
    /// per transaction, after commit or rollback has completely settled, never per-file.
    nonisolated func cleanupWorkspace() throws {
        guard FileManager.default.fileExists(atPath: Self.workspaceDirectory.path) else { return }
        let contents = try FileManager.default.contentsOfDirectory(
            at: Self.workspaceDirectory, includingPropertiesForKeys: nil
        )
        for url in contents {
            try FileManager.default.removeItem(at: url)
        }
    }
}
```

```swift
final class ContentBlockerRequestHandler: NSObject, NSExtensionRequestHandling {
    // Bundle.main inside an app extension resolves to the extension's own bundle ID
    // (com.ADBLX.ADBLX.PrivacyBlocker), not the app's — hardcode the shared app subsystem
    // so Console.app/log stream filtering by "com.ADBLX.ADBLX" catches both.
    private static let logger = Logger(subsystem: "com.ADBLX.ADBLX", category: "AppGroup")

        guard let url = Self.rulesURL() else {
            context.cancelRequest(withError: CocoaError(.fileNoSuchFile))
            return
        }

        guard let itemProvider = NSItemProvider(contentsOf: url) else {
            context.cancelRequest(withError: CocoaError(.fileReadCorruptFile))
            return
```

```swift
// ADBLX/Features/Premium/StoreKitSubscriptionService.swift
import StoreKit

/// StoreKit 2-backed implementation of both `SubscriptionService` (UI-facing) and
/// `EntitlementService` (background-safe) — one source of truth for entitlement state
/// consulted from Premium UI and from `UpdateCoordinator`'s pre-planning entitlement
/// check alike (Sprint 8.0 Commit 8).
final class StoreKitSubscriptionService: SubscriptionService, EntitlementService, Sendable {
    static let annualProductID = "com.ADBLX.ADBLX.premium.annual"
    static let lifetimeProductID = "com.ADBLX.ADBLX.premium.lifetime"

    func fetchStatus() async -> SubscriptionStatus {
        let entitled = await isPremiumEntitled()
        let products = (try? await Product.products(for: [Self.annualProductID, Self.lifetimeProductID])) ?? []

        let annual = products.first(where: { $0.id == Self.annualProductID })
        let lifetime = products.first(where: { $0.id == Self.lifetimeProductID })

        var plans: [SubscriptionPlan] = []
        if let annual {
            plans.append(SubscriptionPlan(
                id: "annual", name: annual.displayName,
                priceDescription: annual.displayPrice, billingPeriodDescription: "per year",
                isCurrentPlan: entitled
            ))
        }
        if let lifetime {
            plans.append(SubscriptionPlan(
                id: "lifetime", name: lifetime.displayName,
                priceDescription: lifetime.displayPrice, billingPeriodDescription: "one-time",
                isCurrentPlan: entitled
            ))
        }

        return SubscriptionStatus(isPremium: entitled, plans: plans)
    }

    func purchase(_ planID: String) async throws -> Bool {
        let productID = planID == "annual" ? Self.annualProductID : Self.lifetimeProductID
        guard let product = try await Product.products(for: [productID]).first else {
            return false
        }
        let result = try await product.purchase()
        switch result {
        case .success(let verification):
            switch verification {
            case .verified(let transaction):
                await transaction.finish()
                return true
            case .unverified:
                return false
            }
        case .userCancelled, .pending:
            return false
        @unknown default:
            return false
        }
    }

    func isPremiumEntitled() async -> Bool {
        for await result in Transaction.currentEntitlements {
            guard case .verified(let transaction) = result else { continue }
            if transaction.productID == Self.annualProductID || transaction.productID == Self.lifetimeProductID {
                return true
            }
        }
        return false
    }
}
```

```swift
enum UpdatePlanner {
    static func plan(
        manifest: FilterManifest,
        installed: [InstalledFilter],
        isPremiumEntitled: Bool
    ) -> UpdatePlan {
        let installedByID = Dictionary(uniqueKeysWithValues: installed.map { ($0.id, $0) })
        var manifestIDs = Set<String>()
        var actions: [UpdateAction] = []
        var installsByGroup: [FilterGroup: [FilterManifest.Entry]] = [:]
        var groupOrder: [FilterGroup] = []

        for entry in manifest.entries {
            manifestIDs.insert(entry.id)

            if let existing = installedByID[entry.id] {
                if existing.installedVersion == entry.version && existing.checksumSHA256 == entry.checksumSHA256 {
                    actions.append(.keep(filterID: entry.id))
                    continue
                }
            } else if entry.premium && !isPremiumEntitled {
                actions.append(.skipPremium(entry))
                continue
            }

            if installsByGroup[entry.group] == nil {
                groupOrder.append(entry.group)
            }
            installsByGroup[entry.group, default: []].append(entry)
        }

        for group in groupOrder {
            actions.append(.install(group: group, entries: installsByGroup[group] ?? []))
        }

        for filter in installed where !manifestIDs.contains(filter.id) {
            actions.append(.remove(filterID: filter.id))
        }

        return UpdatePlan(actions: actions)
    }
}
```

The only change from the original is `else if entry.premium &&
!isPremiumEntitled` (was `else if entry.premium`) — an entitled premium
entry now falls through to the same "new, needs installing" grouping path
as any non-premium entry, exactly matching the spec's "bucketed into
`.install` like any other new entry" requirement.

**Note on Commit 3's three-task split:** the design spec explicitly folds
persistence + removal + rollback + metadata deletion into "one commit"
conceptually (its own text: "those aren't five features... they're the
minimum implementation necessary"). This plan splits that concept across
three *tasks* (3, 4, 5) rather than three *commits* worth of unrelated
half-states, because each task individually produces working, tested,
buildable software: Task 3 alone makes `install()` persist payloads (a safe
additive change — nothing reads `Filters/` yet, so it cannot break anything
existing), Task 4 alone extends rollback to cover a third directory (safe,
tested independently against synthetic files, no `.remove` exists yet to
exercise it in anger), and Task 5 alone adds `.remove` itself, now able to
rely on both prior tasks' guarantees. This satisfies both the spec's "land
together" intent (all three tasks are meaningless without each other and
should be executed back-to-back with no unrelated work interleaved) and
the Task Right-Sizing rule (each task is independently testable and
reviewable, and none leaves the build broken for a later task to fix).

**Placeholder scan:** Task 14 Step 1 is the one intentional exception to "no
placeholders" — it explicitly defers to the implementer reading an existing
test file's established stub pattern rather than guessing at a pattern that
might not match, which is a narrower and safer placeholder than "add
appropriate tests." All other steps in this plan contain complete,
copy-pasteable code.
